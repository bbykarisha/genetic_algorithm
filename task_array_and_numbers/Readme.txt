Описание программы: 
Программа находит вхождение последовательности белка в последовательность
РНК, ищет позицию начала и конца вхождения без пробельных символов, а также
координаты вхождения в тексте, учитывая пробельные символы(строка начала
вхождения и номер в строке, строка конца вхождения и номер в строке).  

Формат входных данных программы: 
Алфавит последовательности РНК: {A,a,U,u,G,g,C,c, -, пробельный символ}.
Алфавит последовательности белка: {A,R,N,D,C,E,Q,G,H,I,L,K,M,F,P,S,T,W,Y,V, 
-, пробельный символ}. Длина последовательности РНК не превышает 10000 
символов, длина последовательности белка не превышает 500 символов. 
Признаком конца ввода обеих последовательностей служит ввод символа точка. 

Формат выходных данных программы:
(координата, координата) позиция начала вхождения - (координата, координата) 
позиция конца вхождения: найденная закодированная последовательность белка
Например, (2, 15) 30 - (3, 12) 47: AUGAUGCUUAUCAUAUAG

Как скомпилировать программу: 
Программу можно скомпилировать ОДНИМ из предложенных способов:
1) fpc array_and_numbers.pas
2) make compile

Как запустить программу:
Программу можно запустить ОДНИМ из предложенных способов:
1) ./array_and_numbers
2) make tests
3) make

Каталог tests содержит тестовые примеры, проверяющие работоспособность программы. 
Например, input_1.txt

Файл Makefile представляет собой действия по компиляции программы из исходных кодов.
